# saas-identity-platform-aspnetcore 功能树

> 多租户 SaaS 身份管理 — ASP.NET Core 8 后端（NSwag codegen 读 shared/openapi.yaml）。
> 与 react/vue/nextjs/springboot 同构（共享 OpenAPI.yaml 单一来源）。字段照抄 BASE（ADR-0024）；结构性对齐按 shared 9/7 重构。

## 模块总览

| 模块 ID | 模块名称 | 说明 | 状态 |
|---|---|---|---|
| M00 | 租户管理 | tenant-admin 配置面：5 F（租户维护 / 租户成员 / 租户角色 / 角色权限 / 租户应用） | 开发中 |
| M01 | 用户管理 | 当前用户视图 + 自然人关系网：4 F（用户维护 / 角色成员 / 租户成员 / SSO 登录） | 开发中 |
| M04 | 应用管理 | 应用 / OAuth client 维度：4 F（应用维护 / 应用启用/停用 / 身份认证 / 菜单管理） | 开发中 |
